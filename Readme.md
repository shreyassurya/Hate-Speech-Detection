# 🧪 Toxic Comment Classification (Mini Project)

This project is a simple, clean, and fast **Toxic Comment Classification** system built for learning and demonstration purposes.  
It classifies comments into **three categories**:

- **0 → Hate Speech**  
- **1 → Offensive Language**  
- **2 → Neither**

The project includes **two machine-learning approaches**:
1. **TF–IDF + Linear SVM (Fast, Traditional ML Model)**  
2. **SBERT + Logistic Regression (Deep Embedding Model)**  

A small **interactive demo UI** is provided inside the Jupyter Notebook.

---

## 🚀 Features

✅ Fast training (suitable for mini-projects)  
✅ Clean preprocessing pipeline  
✅ 2 different ML approaches  
✅ Evaluation with accuracy + classification report  
✅ Notebook-based UI for testing new sentences  
✅ Easy to upload and run on Google Colab  
✅ Perfect for showcasing ML skills in interviews
